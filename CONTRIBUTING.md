# Contributing

Issues and pull requests are welcome for reproducible defects, documentation improvements, compatibility fixes, tests, and bounded new capabilities.

Before opening a pull request:

```bash
python scripts/check_repository_hygiene.py
python scripts/verify_release.py
```

Do not submit credentials, tokens, private keys, device addresses, customer data, raw device responses, or proprietary Fortinet material. Use synthetic fixtures and minimized examples. Security reports must follow [`SECURITY.md`](SECURITY.md).
